# JSCroot sekarang CrootJS

JSCroot sudah berganti nama menjadi **CrootJS** dan pindah ke **[croot.js.org](https://croot.js.org/)**. Situs ini hanya mengalihkan ke sana.

| Dulu | Sekarang |
|---|---|
| jscroot.if.co.id | [croot.js.org](https://croot.js.org/) |
| Library `jscroot/lib` | [`crootjs/lib`](https://github.com/crootjs/lib) |
| Dokumentasi `jscroot/lib/docs` | [croot.js.org/docs](https://croot.js.org/docs/) |

Panduan pindah dari `jscroot/lib` ke `crootjs/lib`: [croot.js.org/lib](https://croot.js.org/lib/).
